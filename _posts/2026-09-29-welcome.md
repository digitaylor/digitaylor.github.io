## This is my first blog post here on GitHub

I’ve had a GitHub account for several years, but have never really thought to use it that much. Recently the blogging platform Listed announced that it would be closing down.

I’ve been using Standard Notes which can easily upload to Listed for the last couple of years and I was very disappointed to learn of its demise.

So now here I am on GitHub again and hopefully this time my Blog has found a permanent home.
